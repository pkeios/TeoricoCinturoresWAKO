# Quiz Kickboxing – Exámenes de cinturón (WAKO / FAK)

Quiz interactivo para estudiar el **cuestionario teórico** de los exámenes de cinturón de la Federación Argentina de Kickboxing (Amarillo → Marrón).

## Qué tiene
- **Teórico:** examen por cinturón (acumulativo, como en la planilla), con tiempo, puntaje y nota de aprobación que sube con el cinturón.
- **Estudiar:** tarjetas para repasar antes de rendir.
- **🧠 Mnemotecnia:** trucos para memorizar y glosario.
- **🥋 Técnico:** programa práctico de cada cinturón, para tener abierto durante el examen e ir tildando.
- **⚖️ Categorías de peso:** categorías oficiales WAKO de tatami y ring.
- Repetición espaciada (las preguntas que fallás vuelven más seguido) y repaso de errores.

## Cómo usarlo
Es un solo archivo: abrí `index.html` en el navegador. El progreso se guarda en el navegador de cada persona.

Para publicarlo como página: *Settings → Pages → Deploy from a branch → `main` / root*.
